<a id="项目简介"></a>
## 项目简介

**字源** 是一个以「十万汉字 · 溯源之旅」为主题的汉字字源可视化网站。它不依赖任何后端，把汉字当作可视化素材，在夜墨底色上用流动的字雨、粒子、星河、字山、字鸟与卷轴，重现汉字的形与神；点击任意汉字可查看其字源、字形演变与字义演变。

<a id="功能特性"></a>
## 功能特性

- **七幕场景**：猴子打字、字雨、字之魂、字之穹、字山、字鸟、卷轴，可自由切换。
- **字鸟群飞**：基于 Reynolds 三规则（分离/对齐/凝聚）的鸟群算法，支持撒食喂鸟、光标驱赶。
- **字符画工具**：上传图片/视频，按亮度映射为汉字字符流，支持保留原比例、点击溯源、导出 PNG。
- **字源详情**：点击汉字弹出详情面板，含 Unicode、部首、笔画、字源类型与三段演变。
- **夜墨设计语言**：深墨底 + 浅墨字 + 朱砂点缀 + 赭石暖光，含胶片颗粒与暗角氛围层。
- **流体交互**：玻璃质感 UI + 光标跟随光 + 语义化缓动曲线（来自 motion-pages）。

<a id="七幕可视化场景"></a>
## 七幕可视化场景

| # | 幕名 | 形态 | 交互 |
|---|------|------|------|
| 0 | 猴子打字 | 任意键随机「打字」出汉字 | 键盘任意键 |
| 1 | 字雨 | 汉字如雨下落，按深度分墨色档 | 点字溯源 / R 换新 |
| 2 | 字之魂 | 粒子汇聚成巨大汉字 | ←→ 浏览 / R 随机 |
| 3 | 字之穹 | 第一人称飞行星系（诗云式） | WASD 飞 / 拖拽转向 / 滚轮调速 |
| 4 | 字山 | 字浪墙 + 动态雁阵 + 月光倒影 | R 换山水 / 点字溯源 |
| 5 | 字鸟 | 字鸟群飞（Reynolds 群飞） | 撒食喂鸟 / 光标驱赶 / R 换群 |
| 6 | 卷轴 | 汉字在卷轴上铺展成文 | R 换文 / 点字溯源 |

<a id="字符画工具"></a>
## 字符画工具

把图片/视频转化为汉字字符流：亮度高 → 密集字形，亮度低 → 稀疏字形；墨色随亮度浮动保持可见；网格按 **contain 比例**贴合原图/视频原始宽高比；点击画布上的字可弹字源详情；支持导出 PNG。

<a id="快速开始"></a>
## 快速开始

```bash
npm install
npm run dev        # 开发服务器（默认 http://127.0.0.1:5173）
npm run build      # 生产构建到 dist/
npm run preview    # 预览构建产物
```

Windows 用户也可直接双击 **`启动字源.bat`** 一键启动。

## 数据来源

网站的全部字源数据（`public/data/`）由 `preprocess.py` 从一份 102,998 字的字源分析 JSON（chars.json）生成：

- 每个汉字 11 个字段（char / unicode / block / radical / strokes / pinyin / origin / glyph_evolution / meaning_evolution / etymology_type / notes）
- 数据由 AI 批量生成（Agnes 免费模型，3 key 并行 + 断点续传 + 质量检查），其中约九成汉字有完整有效的字源分析，其余扩展 B 区以上极生僻字标注「待考」
- 重新生成数据只需准备 chars.json 后运行 `python preprocess.py`

> ⚠️ **数据免责声明**：字源释义由 AI（Agnes 模型）自动生成，未经专家逐条校对，可能存在疏漏或错误，仅供参考。

<a id="设计系统"></a>
## 设计系统

- **语义缓动曲线组**：`--e-out`(进入/悬停)、`--e-in`(离场)、`--e-inout`(页内位移)、`--e-linear`(循环)、`--e-signature`(场景点激活)。
- **流体表面 `.fluid`**：玻璃底 + 顶缘高光 + 空闲扫掠 + 光标跟随光 + 悬停浮起外发光 + `:active{scale:.97}`。
- **氛围层**：`#film-grain`（胶片颗粒）与 `#vignette`（暗角），避免死黑平面。
- **朱砂主 CTA**：搜索/下载按钮用朱砂填充（深底上的深色按钮等于隐形）。

<a id="性能与数据优化"></a>
## 性能与数据优化

- **首屏精简池**：`renderPool.json`（1.1 MB / 2.8 万可渲染汉字）首屏加载，完整 `index.json`（5.2 MB / 10.3 万）后台静默加载。首屏进入从 >15s 降到 **≈1.5s**。
- **数据分片按需**：52 个 chunk 仅在点击溯源或特定场景需要时才经 IndexedDB 缓存加载。
- **背景预渲染**：墨底与纸纹预渲染到离屏画布，每帧只重绘动层。
- **静态数据规范**：数据置于 `public/`，引用用 `/data/...`（Vite 构建自动拷贝；`/src/` 路径在生产构建会失效）。

<a id="质量门禁"></a>
## 质量门禁

使用 motion-pages 的 `audit.mjs` 做设计审查（无头 Chrome 驱动）：覆盖 AI-slop 检查、动效语法、技术（控制台错误/空白帧/对比度）、可访问性。当前成绩：**desktop / tablet 0 warn · 0 fail；phone 0 fail**。

<a id="已知事项"></a>
## 已知事项

- `vite build` 清理 `dist` 时 Windows trash shim 可能报错 → 先 `rm -rf dist` 再 build。
- 字体仅约 2.8 万字形可渲染（Alibaba PuHuiTi 实测 cmap），扩展 B/C/D 区字符会回退为「待考」或无法显示。
- 底部场景切换圆点较小（紧凑设计），已用 `::after` 撑出无重叠命中区；如要彻底消除审计 warn 可加大视觉点。
